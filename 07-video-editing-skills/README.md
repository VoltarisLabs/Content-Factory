# Video editing skills

Editing skills for short-form vertical video, one skill per folder.
Each `SKILL.md` says when to use it, the steps, the rules and what to check before moving on.

| Skill | What it does |
|---|---|
| [cut-the-dead-air](cut-the-dead-air/SKILL.md) | Tightens a talking head take: pauses, breaths, false starts, retakes |
| [b-roll-and-pacing](b-roll-and-pacing/SKILL.md) | Keeps the picture moving and showing what is being said |
| [short-form-captions](short-form-captions/SKILL.md) | Burned-in captions that read fast and stay clear of the app's buttons |
| [audio-mix-for-reels](audio-mix-for-reels/SKILL.md) | Voice first, music under it, sound effects on the frame |
| [export-for-social](export-for-social/SKILL.md) | Export settings and the final check before posting |

Work through them in this order: cut, b-roll, captions, audio, export.
