# Content Factory

What we learned making short-form reels, from watching other creators' videos and from our own post analytics.
Lessons, case studies, editing skills and a sound kit. There is nothing to install or run.

```
Content-Factory/
├── 01-skills-from-videos/     what other creators' videos taught us
├── 02-hooks-and-openers/      which openings held viewers and which didn't
├── 03-topics-that-travel/     which subjects reach people and get shared
├── 04-analytics/              what our own numbers proved
├── 05-case-studies/           reels that travelled and reels that flopped
├── 06-sound-kit/              sound effects and music picks
└── 07-video-editing-skills/   cutting, b-roll, captions, audio mix, export
```

Each folder has a README with a table of its files.
Each lesson is a rule in bold, then the evidence from real posts. Dates are 2026. Labels like BC-079 are our internal numbers for past posts.
